¿Cómo se alimenta la tienda?

ImageKit → exportación automática → CLIP local en GitHub Actions → propuestas IA → revisión humana → catálogo comercial. Una fotografía no demuestra automáticamente un producto distinto, una talla, una marca auténtica ni existencias.

Los nombres, marcas y categorías que confirmes aquí se exportan como JSON compatible con la tienda. No se modifica products.json ni se publica automáticamente.
